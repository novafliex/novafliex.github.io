Go 基础：测试函数

先理解测试在做什么

Go 使用标准库 testing 编写自动化测试。测试不是为了证明代码永远正确，而是用一组确定的输入，检查代码能否得到预期结果。

核心流程

准备数据 → 执行代码 → 检查结果 → PASS / FAIL

开始前先记住下面四点：

关键词 含义
_test.go 测试文件
TestXxx 测试函数
*testing.T 当前测试的控制对象
go test 编译并执行测试

二、testing.T 是什么

t *testing.T 代表当前测试，负责记录日志、标记失败和控制测试流程。

常用方法：

方法 作用
t.Log() / t.Logf() 记录测试日志
t.Error() / t.Errorf() 标记失败，但继续执行当前测试
t.Fatal() / t.Fatalf() 标记失败，并立即结束当前测试
t.Helper() 标记当前函数是测试辅助函数
t.Run() 创建并运行子测试

Error 和 Fatal 的区别

如果错误发生后，后续代码已经没有执行意义，就使用 Fatal：

选择原则： 后续检查仍有意义时用 Error；前置条件已经失败、继续执行可能产生误导时用 Fatal。

常用断言：

断言 检查内容
require.NoError(t, err) 没有错误
require.Equal(t, want, got) 预期值与实际值相等
require.NotEqual(t, want, got) 两个值不相等
require.NotEmpty(t, value) 值不为空
require.True(t, condition) 条件为 true

require 不是 Go 标准库。它来自 testify，并且断言失败后会立即结束当前测试，效果更接近 t.Fatal()。

五、表驱动测试：一次覆盖多组输入

同一个函数需要测试多组输入时，不必重复写多个测试函数。Go 中常用“表驱动测试”：

表驱动测试的三个重点：

  • 测试数据集中放在切片中。
  • t.Run() 为每组数据创建一个子测试。
  • 新增场景时，只需要增加一组测试数据。

六、运行测试

命令 用途
go test 测试当前包
go test -v 显示详细测试过程
go test ./... 测试当前模块的所有包
go test -run TestAdd -v 只运行名称匹配的测试
go test -cover ./... 查看测试覆盖率

执行结束后，PASS 表示测试通过；FAIL 表示至少有一个测试失败。

七、快速复盘

关键词 速记
t.Error 标记失败，继续执行
t.Fatal 标记失败，立即结束当前测试
t.Helper 标记测试辅助函数
t.Run 运行子测试
require.Equal 使用第三方库比较结果

一句话理解： Go 测试就是准备输入、调用代码，再用 testing.T 检查实际结果是否符合预期。
